## Observaciones principales
- `2evidences.routes.js` y `report.routes.js` no aparecen montados en `backend/src/app.js`; tratarlos como posible legacy hasta confirmar.
- `ai-compliance.routes.js` contiene dos `GET /engine-health`; revisar precedencia de Express antes de limpiar.
- `admin-saas.routes.js` contiene `POST /tenants/:tenant_id/standards/:standard_code/initialize-controls` duplicado por parser; confirmar si hay definición repetida real.
- Muchas rutas reciben `tenant_id` por params aunque el usuario ya trae tenant en JWT. Esto no necesariamente es falla, pero exige validación por ruta para evitar acceso cross-tenant.
