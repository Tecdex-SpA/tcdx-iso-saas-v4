# UI VISUAL BENCHMARKS

## Baseline aprobado

La unica referencia visual normativa de UI-02 es:

`references/ui02-executive-grc-workspace-v2.png`

Representa la direccion **B - Executive GRC Workspace** ajustada mediante Product Design. Las referencias anteriores fueron retiradas para evitar instrucciones visuales incompatibles.

## Que debe compararse

- Sidebar navy/grafito, compacto y con estado activo naranja.
- Topbar discreta con contexto, busqueda y usuario.
- Header de workspace sobrio y acciones claras.
- KPI strip compacto, no cards gigantes.
- Franja de prioridades accionables.
- Tabs y filtros como controles de trabajo.
- Tabla enterprise como superficie primaria.
- Drawer derecho para detalle contextual.
- Data Trust separado del nivel de riesgo y del estado de cumplimiento.
- IA contextual integrada y visualmente secundaria a la decision humana.

## Limites de la imagen

Los textos, cifras, tenant, fechas e IDs de la imagen son ilustrativos. La implementacion debe usar datos reales y contratos existentes. La imagen no autoriza hardcodes, cambios funcionales ni eliminacion de rutas.

Los benchmarks externos sirven solo para comprender madurez enterprise GRC. No deben copiarse marcas, layouts propietarios ni estilos ajenos literalmente.
