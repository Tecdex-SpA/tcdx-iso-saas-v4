Consultar antes de modificar UI:
1. `references/executive-dashboard.png`
2. `references/grc-workspace.png`
3. `references/risk-dashboard.png`
4. `references/compliance-view.png`

Los benchmarks externos sirven solo para comprender patrones enterprise GRC. La implementacion final debe ser TCDX y respetar el Design System.

## Criterios de comparacion
- Sidebar grafito/gris oscuro y compacto.
- Header discreto.
- Densidad enterprise alta pero legible.
- Cards KPI compactas.
- Tablas como superficie principal de trabajo cuando corresponda.
- Filtros en una sola franja funcional.
- Panel lateral para detalle cuando evita navegar innecesariamente.
- Charts sobrios, legibles y semanticos.
