# UI_DESIGN_TARGET — TCDX ISO SaaS v4

## Objetivo obligatorio
La interfaz debe reproducir la calidad visual, densidad, jerarquia, composicion y patrones mostrados en `docs/codex/ui/references/*.png`. Estas referencias son el baseline visual de aceptacion, no inspiracion opcional.

## Identidad visual
- El repositorio `Tecdex-SpA/tecdex-design-system` es la fuente normativa de marca y se consulta READ-ONLY.
- Sidebar: grafito/gris carbon, no azul dominante. Usar una familia de grises TecDex; el contraste debe provenir de luminancia y estados, no de saturacion azul.
- Superficies de contenido: blanco y grises muy claros.
- Color semantico reservado: verde exito/cumplimiento, ambar advertencia, rojo criticidad/no conformidad, azul/teal solo informacion puntual.
- Evitar gradientes decorativos, neon, glassmorphism, cards infladas y estetica startup.

## Regla de fidelidad
Codex NO debe reinterpretar el lenguaje visual ni proponer un sistema alternativo. Ante ambiguedad debe conservar el patron existente en las referencias y Design System.
