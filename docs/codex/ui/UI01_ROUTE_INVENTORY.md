**Discrepancia documental detectada:** el commit de `main` ya contiene el merge F6.14-A, pero `CURRENT_STATE.md`, `ARCHITECTURE_MAP.md`, `PHASE6_EXPANDED_CLOSURE.md` y `handoffs/6.14-A.md` todavía expresan `F6_14_A_RUNTIME=PENDING_USER_DEPLOY_VALIDATION`. ## Hallazgos de navegación actual

El Sidebar ya contiene una primera consolidación conceptual: Cumplimiento agrupa diagnóstico/health/controles/SOA/ciclo de vida/auditoría/hallazgos/NC; Riesgos agrupa matriz y activos; Planes agrupa plan singular y acciones recomendadas; Configuración agrupa usuarios/perfil/perfil empresa. Sin embargo, el cliente máximo todavía puede recibir 18 entradas y coexisten tres puertas GRC (`grc-global`, `operaciones-grc`, `grc`), más `datos`, `metricas`, `bi`, Report Studio e IA Compliance. UI-01 recomienda mantener los contratos pero reducir las puertas principales a dominios de trabajo.
