# UI_COMPONENT_RULES

## Regla de reutilizacion
Antes de crear un componente, buscar equivalentes en el proyecto y en `tecdex-design-system`. No duplicar componentes ni introducir una segunda libreria visual.

## Componentes
- Sidebar: grafito/gris carbon, ancho estable, iconografia simple, active state inequívoco.
- KPI cards: compactas, titulo corto, valor dominante, delta/contexto secundario.
- Tables: encabezado claro, sorting/filtros/acciones consistentes, densidad enterprise.
- Badges: solo colores semanticos definidos.
- Charts: leyenda clara, labels legibles, sin decoracion superflua.
- Detail drawer/panel: contexto sin perder la lista principal.

## Prohibiciones
No inventar paletas, radios, sombras, tipografias, layouts, navegacion o variantes de componentes fuera del baseline sin evidencia del Design System.
