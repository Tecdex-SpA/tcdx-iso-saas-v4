## Architectural Decision

Decision: existing structures are sufficient for 6.9-02 adapters.

6.9-01 does not create a canonical graph edge table. 6.9-02 may implement a traversal interface over:

- canonical Observation/Gaps;
- domain-specific relation tables;
- generic controlled relations;
- deterministic projections.

Persistence in 6.9-02, if any, must be justified as derived/cache/traversal state and must not become a second source of truth.

## Required Relationship Decisions

| Relationship | Decision |
|---|---|
| requirement-control | `grc_requirement_control_mappings` is source of truth. |
| control-evidence | `grc_evidence_links` and audit-specific `grc_audit_evidence_links` are source of truth by context. |
| risk-control | Use domain sources (`iso_risk_matrix_items`, `privacy_dpia_risks`, `grc_control_assurance`) and controlled generic relations where explicitly present. |
| finding-action | `grc_audit_followups` is the confirmed audit-domain relation; findings are not automatic Gaps. |
| supplier relationships | `grc_supplier_*`, `privacy_processors`, `grc_incidents.supplier_id` remain authoritative domain sources. |
| asset/process | `assets.primary_process_id`, `tenant_process_entity_links`, `grc_operational_dependencies`, supplier services and incident context are separate domain truths. |
| metric relationships | Math Governance metric/source/trust bindings are protected canonical data contracts; `grc_metric_observations` remains domain-specific. |
| regulation/legal obligation | `grc_obligations.requirement_id` and incident notification obligation links exist; general Regulatory Intelligence remains planned in 6.11 and is not invented here. |
| observation relationships | `grc_observation_relations` is canonical; no `grc_observation_links`. |
| gap relationships | `grc_gaps` plus `grc_observation_relations` Observation -> Gap is canonical. |
