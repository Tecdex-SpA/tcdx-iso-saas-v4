## Service Behavior

`regulatoryDiffPacks.service.js` provides:

- deterministic semantic diff over same-regulation `regulation_versions`;
- text section changes by section/anchor/checksum and token similarity;
- obligation changes and lineage without overwriting historical obligations;
- version temporality changes separating publication/effective/legal validity from technical evaluation;
- pack definition/version composition by canonical references;
- tenant activation using tenant from auth context;
- tenant applicability draft recommendation with provenance and human confirmation gate.
