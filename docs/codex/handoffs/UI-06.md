## Decision / root cause

UI-06 debía profesionalizar visualizaciones existentes, no crear nuevas fuentes ni nuevas fórmulas.

Decisiones:

- Se reutilizó `ResponsiveChartFrame` en vez de crear una segunda librería gráfica.
- Se mantuvo `DataTrustIndicator` como única representación de Data Trust real.
- No se recalculó confianza, health, riesgo, cumplimiento ni agregaciones backend en frontend.
- Los charts de tendencia usan sólo histórico oficial suficiente; `null`, `insufficient` y `not_calculable` quedan fuera de la línea y se representan como estado universal.
- BI/exportes/reportes no se rediseñaron porque en el alcance focal no tenían charts reales que justificaran nueva visualización.

## DATA_GAP

- Snapshot oficial con `value=null` o estado no calculable no se dibuja como punto cero.
- Histórico con menos de dos snapshots calculados muestra `Datos insuficientes`.
- Comparación marcada como `methodology_compatible=false` bloquea el chart y muestra `Histórico no comparable`.
- Si Data Trust no existe, se conserva `No disponible` vía componentes existentes.
