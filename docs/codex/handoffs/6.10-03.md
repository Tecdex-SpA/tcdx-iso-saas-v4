## Architecture Decision

Decision:

```text
PGVECTOR_FIRST = PASS
EXTEND_KB_V2 = PASS
SECOND_KB_CREATED = 0
SECOND_CHUNK_TRUTH = 0
```

Implemented a separate embedding-side table:

```text
knowledge_document_chunks (canonical chunk text)
  -> knowledge_chunk_embeddings (versioned pgvector embeddings)
```

Rationale:

- supports multiple provider/model/model_version/dimensions combinations;
- supports reindex and stale history without overwriting chunks;
- avoids adding provider-specific columns to the canonical chunk model;
- avoids copying `chunk_text` into a second truth store;
- enforces tenant scope through explicit `tenant_id` plus composite FK `(tenant_id, chunk_id)`.

## Provider / Model Strategy

- Provider/model/model_version/dimensions are required config or service input.
- No product model or dimension is hardcoded.
- OpenAI adapter exists only when `provider=openai`, `OPENAI_API_KEY` and model/dimensions are configured.
- Tests inject a fixture provider to avoid external calls.
- If provider is missing/unsupported/fails, the service persists `status='failed'` and does not fabricate vectors.

## Reindex / Lifecycle

Reindex is required when any of the following changes:

```text
chunk text_checksum
embedding provider
embedding model
embedding model_version
embedding dimensions
embedding contract version
```

Existing embeddings for the same tenant/chunk/model identity with a different input checksum are marked `stale`.

Document lifecycle integration:

- `active` documents can be embedded.
- non-indexable lifecycle states persist `status='skipped'`.
- provider failures persist `status='failed'`.
- ready rows require non-null vector/checksum/generated timestamp.

## Search Primitive

`searchTenantVectorCandidates` is a limited technical primitive for pgvector validation and future 6.10-04 reuse.

It:

- filters `tenant_id` in SQL before `ORDER BY embedding <=> query_vector`;
- joins active TENANT documents and same-tenant chunks;
- caps `limit` at 50;
- returns chunk IDs, document IDs, distance and embedding metadata;
- does not return generated answers, citations, hybrid lexical/graph ranking or reranker output.
