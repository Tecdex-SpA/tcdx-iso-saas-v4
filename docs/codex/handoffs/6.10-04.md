## Implementation

- Contract version: `hybrid-retrieval-contract-v1`
- Ranking version: `hybrid-rank-weighted-rank-normalization-v1`
- Service: `backend/src/services/knowledge-base/knowledgeHybridRetrieval.service.js`
- API: `POST /api/knowledge-base/retrieval/search`

Flow:

```text
query/query_embedding
  -> lexical retrieval over knowledge_document_chunks
  -> vector retrieval over knowledge_chunk_embeddings
  -> rank normalization per method
  -> weighted deterministic hybrid ranking
  -> tenant-scoped candidates with provenance
```

## Lexical Retrieval

- SQL filters `c.tenant_id=$tenant` and `d.tenant_id=$tenant` before candidate selection.
- Uses canonical `knowledge_document_chunks.chunk_text`.
- Does not copy chunk text to another table.
- Filters lifecycle to `knowledge_documents.status='active'`.
- Supports document filters: `document_type`, `classification`, `document_key`, `document_version`, `source_authority`, `knowledge_document_id`, `chunk_id`, `as_of`.
- Query tokens are bounded and query length is capped.

## Vector Retrieval

- Reuses `knowledge_chunk_embeddings`.
- Uses only `status='ready'`.
- Requires matching `embedding_contract_version`, provider, model, model_version and dimensions.
- Excludes `stale`, `failed`, `skipped`, `pending` and incompatible embeddings.
- SQL filters tenant before pgvector distance ranking.
- Uses F6.10-03 `vectorLiteral` dimension validation.

## Ranking

Scores are explicit and reconstructable:

```text
vector_score = normalized vector rank
lexical_score = normalized lexical rank
hybrid_score = 100 * (vector_weight * vector_score + lexical_weight * lexical_score)
```

Defaults:

```text
vector_weight = 0.55
lexical_weight = 0.45
```

Weights are normalized when overridden. Tie-break:

```text
hybrid_score desc
vector_score desc
lexical_score desc
knowledge_document_id asc
chunk_id asc
```

No LLM scoring.

## Provenance

Each candidate includes:

- tenant/document/chunk/version IDs;
- document key/type/classification/status/scope/source authority;
- chunk ordinal, checksum, page/section/heading/offset metadata;
- hybrid/vector/lexical scores and method ranks;
- retrieval contract version;
- ranking version;
- embedding contract/provider/model/model_version/dimensions/checksums where vector retrieval participated;
- source table provenance.
