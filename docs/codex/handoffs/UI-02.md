- `Risk matrixs` queda eliminado mediante traduccion focal plural/singular en `displayText`, sin guards globales peligrosos.
- `GrcDecisionCenter` ya no emite copy hardcodeado en espanol cuando el locale activo es ingles.
- El harness de evidencia visual fuerza locale soportado `es-CL`/`tcdx_locale=es` y usa un UUID runtime generado para tenant/user en storage, cookie y JWT de prueba visual, sin hardcodear tenant en codigo productivo.
- Manifest visual ahora falla ante error visible de tenant, auth, `Risk matrixs`, breadcrumbs duplicados o mezcla conocida de labels ingles/espanol para el locale capturado.
- No se modifico `mvpPermissions.ts`, `FEATURE_ACCESS`, `MVP_ROUTE_RULES`, `CAPABILITY_BY_PATH`, roles, modulos, capabilities, entitlements, route guards, backend, API, DB, Math Governance, Data Trust de logica ni las 97 rutas App Router.

Causas raiz:

- Locale mixto: el script de capturas de Etapa 2.1 no fijaba `tcdx_locale`, cookie ni `Accept-Language`; Playwright resolvia `navigator.language=en-US`, mientras contenido legacy/hardcodeado seguia en espanol.
- Tenant invalido: el harness anterior exponia nombre de tenant desde mocks visuales, pero el token/contexto usado por `resolveEffectiveTenantContext` contenia un tenant no UUID; `GrcDecisionCenter` rechazaba la sesion como invalida.
- Manifest invalido: Etapa 2.1 no validaba patrones visibles de error de tenant ni mezcla de idiomas, por lo que podia declarar PASS con error visible en screenshot.
