- Se agregaron primitivas pequenas, no una segunda libreria: `EnterpriseFilterBar` y `EnterpriseRowActions`.
- `EnterpriseTableShell` se extendio con `density="compact"` y `footer` para reutilizacion.
- No se implemento sorting frontend enganoso sobre datos paginados; se preservo la paginacion/orden backend existente en `/metricas` y la local existente en `/riesgos`.
- No se agregaron filtros sin soporte real.
- Los valores raw user-facing se localizaron en UI cuando habia traduccion clara; no se modificaron contratos backend.
- Data Trust se conserva en el nivel existente y no se recalcula ni mezcla con confidence IA.
