## Eligibility Rules

Eligible only when all hold:

- `status = calculated`
- `observed_at` is explicit from result/completed/period context
- `calculation_run_id` exists
- source snapshot belongs to the same tenant/run
- Data Trust state is `TRUSTED_WITH_WARNINGS` or `LOW_CONFIDENCE`

Severity mapping is explicit and rule-owned:

```text
TRUSTED_WITH_WARNINGS -> low
LOW_CONFIDENCE -> medium
```

## Non-Eligibility Rules

These produce `ignored` outbox events and no Observation:

```text
source_unavailable
source_incompatible
SOURCE_SCHEMA_INCOMPATIBLE
SOURCE_DATA_INSUFFICIENT
FORMULA_DEPENDENCY_PENDING
FORMULA_VARIABLE_REQUIRED
FORMULA_ZERO_WEIGHTS
dependency_pending
not_calculable
unmeasured
failed
TRUSTED/no material signal
observed_at_missing
```

Therefore:

```text
NO_DATA != NEGATIVE_OBSERVATION
INSUFFICIENT_DATA != FAILURE
SOURCE_INCOMPATIBLE != BUSINESS_FINDING
```

## Idempotency / Retry / Supersession

- Outbox idempotency key includes tenant + producer run/snapshot + rule + formula + period.
- Canonical Observation identity excludes run/snapshot and uses tenant + producer type + rule + formula + period + source contract.
- Replaying the same event does not duplicate outbox or Observation rows.
- A later eligible run for the same formula/period/rule creates a new outbox event and triggers Semantic Layer supersession of the previous current Observation.
- Retry states: `pending`, `processing`, `failed`, `dead_letter`, `completed`, `ignored`.
- `processNextPending` processes tenant-scoped `pending/failed` events by `next_attempt_at`.

## Provenance / Lineage / Data Trust

Outbox payload and canonical Observation metadata preserve:

- tenant id
- calculation run id
- source snapshot id
- formula code/version
- source code/contract
- physical sources
- source counts
- source status
- machine reason
- Data Trust state/reasons
- correlation id
- rule code/version
- warnings and decision payload

Canonical lineage remains owned by Semantic Layer through `createManualObservation`.

## Tenant Isolation / RBAC / System Actor

- Every outbox event carries `tenant_id`.
- Processing by a different tenant returns `OBSERVATION_EMITTER_EVENT_NOT_FOUND`.
- Calculation run and snapshot are validated against the event tenant before Semantic Layer persistence.
- Orchestrator passes the existing requester as actor; no endpoint/RBAC bypass was added.
- No UI or public route was added in this WP.
