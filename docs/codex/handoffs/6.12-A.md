## Service Behavior

`crossGrcIntelligence.service.js` provides:

- tenant-required unified context builder;
- separated context categories for facts, derived signals, retrieved knowledge, regulatory context, historical context and missing/insufficient context;
- deterministic pattern/trend evaluation with min-period guard;
- deterministic anomaly evaluation with robust z-score/MAD and sparse/zero-variance guards;
- Cross-GRC orchestration over existing Priority, Impact Graph, RAG and regulatory adapters;
- partial dependency behavior with `dependency_pending` warnings instead of fabricated results.

## AI Engine Boundary

`ai-engine/app/services/context_builder.py` now:

- returns `tenant_scope_required` without DB reads when no tenant is authorized;
- includes `canonical-intelligence-context-v1` provenance;
- keeps fallback from standard-specific query to tenant-wide query as explicit opt-in via `allow_standard_fallback`;
- preserves `missing_is_not_zero` and `no_cross_tenant_fallback` metadata.
