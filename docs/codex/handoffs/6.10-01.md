## Scope And Tenant Semantics

- `GLOBAL`: `tenant_id=NULL`.
- `REGULATORY`: `tenant_id=NULL`, `source_authority=authoritative`.
- `TENANT`: `tenant_id` required.
- Service list/get returns global/regulatory plus same-tenant private documents only.
- Empty tenant with private scope returns a valid empty collection.
- DB constraint `knowledge_documents_tenant_scope_check` enforces scope/tenant validity.

## Versioning

- Unique index: `(scope, COALESCE(tenant_id, zero uuid), document_key, version)`.
- `supersedes_document_id` points to the previous document row.
- `updated_at` is not document versioning.
- New versions insert new rows and do not overwrite prior rows.
- Checksums detect content/original/extracted changes.
