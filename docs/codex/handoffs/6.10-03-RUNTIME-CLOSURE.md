## Decisiones cerradas

1. `knowledge_document_chunks` conserva ownership exclusivo del texto del chunk.
2. `knowledge_chunk_embeddings` es almacenamiento embedding-side; no duplica `chunk_text`.
3. Vector retrieval debe filtrar tenant antes de aplicar distancia vectorial.
4. Provider, model, model version y dimensions permanecen configurables/versionados; no se fija una dimensión productiva específica en código.
5. Cambios de input/provider/model/version/dimensions/contract generan reindex/versionamiento y no mutación silenciosa de identidad histórica.
6. Sólo documentos en lifecycle indexable pueden producir embeddings `ready`.
7. No se crea KB v3 ni vector DB externo.
8. Hybrid Retrieval, RAG answer contract, citations y reranking continúan fuera de F6.10-03.
9. No se modificaron fórmulas ni source contracts de Math Governance.
