# Catálogo funcional de indicadores

Este catálogo define conceptos de negocio. Los códigos de fórmula y expresiones permanecen en el anexo técnico y no se muestran como contenido principal. Umbrales numéricos son defaults propuestos, versionables por metodología o tenant; no son certificación ni criterio ISO oficial.

## Contrato visible común

Todo consumidor debe mostrar: nombre, resultado, estado, tendencia, objetivo, cobertura, confianza, interpretación, causa, impacto GRC, recomendación, acción, fuente resumida y fecha. Si no existe fuente suficiente, el estado es `sin medición` y nunca cero.

## Anexo técnico de asociaciones internas

| Código funcional | Fórmulas internas actuales | Nota de gobierno |
|---|---|---|
| GRC-HEALTH | `F5_5_GRC_HEALTH` | Pesos y componentes se versionan; faltantes no se convierten en cero. |
| ISO-READINESS | `F5_5_READINESS` | La etiqueta visible no afirma certificación. |
| COMPLIANCE | `F5_5_COMPLIANCE_WEIGHTED` | Debe acompañarse siempre de `COVERAGE`. |
| COVERAGE | `F5_5_COVERAGE` | `no aplica` aprobado se excluye. |
| RISK-INHERENT | `F5_5_INHERENT_RISK` | Metodología y escala obligatorias. |
| RISK-RESIDUAL | `F5_5_RESIDUAL_RISK` | Efectividad proviene de output oficial. |
| CONTROL-EFFECT | `F5_5_CONTROL_EFFECTIVENESS`, `F5_5_COMBINED_EFFECTIVENESS` | No sumar porcentajes de controles. |
| EVIDENCE-FRESH | `F5_5_FRESHNESS_CONTINUOUS`, score de evidencia versionado | La relación evidencia-control/requisito es parte de la cobertura. |
| REMEDIATION | `F5_5_WEIGHTED_PROGRESS`, `F5_5_OVERDUE_RATE`, `F5_5_PERCENT_VARIATION` | Cierre requiere re-test. |
| FINDINGS | `F5_5_SEVERITY_INDEX`, `F5_5_AGE`, `F5_5_CLOSURE_RATE` | Timezone y período explícitos. |
| ACTIONS | `F5_5_CLOSURE_RATE`, `F5_5_MTTC`, `F5_5_WEIGHTED_PROGRESS`, `F5_5_OVERDUE_RATE` | Métricas por severidad y owner. |
| AUDIT-ASSURANCE | `F5_5_ASSURANCE_SCORE`, `F5_5_SAMPLE_SIZE`, `F5_5_FAILURE_RATE` | `inconclusive` no es pass. |
| SUPPLIER-RISK | `F5_5_SUPPLIER_RISK`, `F5_5_RESIDUAL_RISK` | Health usa datos relacionados, no constantes. |
| CONTINUITY | `F5_5_AVAILABILITY`, `F5_5_MTBF`, `F5_5_MTTR`, `F5_5_SLA_COMPLIANCE`, `F5_5_RTO_GAP`, `F5_5_RPO_GAP` | Unidades obligatorias. |
| INCIDENTS | `F5_5_SEVERITY_INDEX`, `F5_5_MTTC`, `F5_5_CLOSURE_RATE` | Reincidencia requiere observaciones canónicas en 5-C2. |
| LOSSES | `F5_5_NET_LOSS`, `F5_5_EXPECTED_LOSS`, `F5_5_LOSS_SEVERITY`, `F5_5_PARAMETRIC_VAR`, `F5_5_MONTE_CARLO` | Segregar moneda y validar supuestos. |
| DATA-TRUST | `F5_5_COMPLETENESS`, `F5_5_ACCURACY`, `F5_5_CONSISTENCY`, `F5_5_FRESHNESS_CONTINUOUS`, `F5_5_LINEAGE_SCORE` | Score compuesto se gobierna en 5-C3. |
| MATURITY | `F5_5_MATURITY` | Modelo y evidencia versionados. |
| OP-PERFORMANCE | health compuesto existente, pendiente de versión específica en 5-C3 | No reutilizar nombre con pesos distintos. |
| CONTROL-COVERAGE | `F5_5_CONTROL_COVERAGE` | Universo relevante debe quedar snapshot. |
| SLA-COMPLIANCE | `F5_5_SLA_COMPLIANCE` | Calendario y timezone son parte del contrato. |
| SUPPLIER-HEALTH | `F5_5_SUPPLIER_RISK`, componentes health versionados | No publicar health alto con fuente desconocida. |

El anexo es visible solo para `platform_admin`, `data_steward`, soporte Tecdex autorizado o auditor con permiso metodológico explícito.
