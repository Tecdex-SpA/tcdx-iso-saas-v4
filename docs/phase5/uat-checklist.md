# Fase 5 — UAT checklist

- Crear dominio y elemento de datos.
- Registrar evaluación de calidad.
- Crear métrica tenant con fórmula declarativa.
- Publicar fórmula.
- Registrar medición manual con evidencia.
- Validar medición.
- Ver tendencia y trust score.
- Crear encuesta, versión, campaña, respuesta y evaluación.
- Crear test de assurance, ejecución, resultado y revisión.
- Crear evento de pérdida, recuperación y cierre.
- Crear dashboard con widget, publicar y snapshot.
- Crear reporte, generar PDF/DOCX/XLSX, aprobar y descargar.
- Validar que tenant B no ve datos de tenant A.
