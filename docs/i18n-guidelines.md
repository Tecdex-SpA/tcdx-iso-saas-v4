# Guía i18n TCDX ISO SaaS

- Usar useTranslation para textos visibles.
- Usar statusLabels para estados, prioridades, severidades y health.
- No traducir datos de cliente, nombres de empresas, usuarios, controles, evidencias, hallazgos ni comentarios históricos.
- El valor original se usa para lógica y filtros.
- La traducción se usa solo para presentación.
- Ejecutar scripts/qa-bilingual-full.sh antes de cerrar cambios i18n.
