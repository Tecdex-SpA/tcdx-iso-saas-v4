# Loss Methodologies

Estado: Paquete 4 completed.

## Formulas

- Net Loss = Gross Loss - Recoveries.
- Expected Loss = Frequency * Mean Severity.
- Parametric VaR = mu + z * sigma.
- Monte Carlo: frecuencia Poisson y severidad fija, PERT o lognormal con semilla reproducible.

## Reglas

- Recuperaciones no pueden superar perdida bruta.
- No se mezclan monedas sin tipo de cambio oficial.
- VaR requiere muestra suficiente y desviacion positiva.
- Monte Carlo requiere semilla en pruebas.
