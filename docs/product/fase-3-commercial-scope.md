# Fase 3 - Alcance comercial

## Capacidad visible

La capability `grc_phase3_operations` habilita gestión operacional integrada al GRC:
unidades, procesos, servicios, continuidad, BIA, KPI/KRI y análisis cuantitativo
simplificado de riesgos.

## Lenguaje permitido

- Apoya la gestión de riesgos y continuidad.
- Facilita trazabilidad para preparación y ejecución de auditorías.
- Proporciona alertas, prioridades y evidencia para revisión humana.
- Calcula métricas determinísticas basadas en datos registrados.

## Límites

La plataforma no certifica, no garantiza cumplimiento, no reemplaza auditorías y no
toma decisiones finales automatizadas. Las recomendaciones de hallazgo, no conformidad
y acción requieren revisión y autorización de una persona con permiso.
