# Evidence Library UX

## Target Experience

`/evidencias` is organized as:

1. Fuentes documentales.
2. Biblioteca documental.
3. Panel de detalle.

## Source Cards

Cards show:

- source name;
- status;
- document count;
- last sync/index time.

## Library

The library shows normalized documents from:

- `document_index`;
- `evidences`.

Default view shows only the active/latest document per dedupe key.

## Detail Tabs

- Resumen
- Asociaciones
- Sugerencias
- Fragmentos
- Versiones
- Historial

## Human Review

Semantic suggestions are not applied automatically. A user with management permission must accept or reject them.
