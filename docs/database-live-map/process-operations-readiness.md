## Brechas
- Falta o está incompleta una entidad transversal clara `tenant_processes` / `tenant_operations`.
- Los módulos core parecen más orientados a tenant/norma/control/evidencia que a proceso de negocio.
- Para salud por proceso se requiere normalizar relación proceso -> operación -> norma/control -> evidencia/riesgo/acción.

## Propuesta conceptual futura, sin implementar
- `tenant_processes`: tenant_id, name, description, owner_user_id, area, criticality, status, timestamps.
- `tenant_operations`: tenant_id, process_id, name, frequency, owner_user_id, status.
- Relaciones puente: process_controls, process_evidences, process_risks, process_action_plans, process_kpis.
- Vistas agregadas: health_by_process, compliance_by_process, overdue_actions_by_process, risk_by_process.
- IA/RAG: incluir process_id/operation_id en context builders para trazabilidad operacional.

Fuente: `information_schema.tables`, `information_schema.columns`.
