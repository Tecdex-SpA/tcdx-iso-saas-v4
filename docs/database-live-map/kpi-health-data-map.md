## Brechas para procesos/operaciones
La estructura muestra health/KPI por tenant, norma, control y snapshots, pero el soporte directo por proceso/operación es limitado o parcial. Para cumplimiento por proceso se recomienda introducir una dimensión operacional formal antes de ampliar reportes y dashboards.
